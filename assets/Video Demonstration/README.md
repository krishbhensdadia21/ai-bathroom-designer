## 📋 Demonstration Highlights
1. **Interactive 3D WebGL Studio**:
   - 360° Orbit View, 2D Architectural Floor Plan, and 1st-Person Walk-In Mode.
   - Photorealistic procedural PBR materials (Calacatta Quartz, Teak, Welsh Slate).
   - Circadian Lighting Simulation (Day 5000K, Dusk 2700K, Night).

2. **Dual-Pathway Generative AI Assistant**:
   - Predefined Parametric Constraints vs. Natural-Language Wishlist Mode.
   - Real-time prompt sanitization via Meta Llama Prompt Guard 22M.
   - Fast spatial layout synthesis powered by Llama 3.3 70B in `< 3 seconds`.

3. **Engineering Rigor & Building Codes**:
   - Strict NKBA & ADA physical clearance enforcement (21″ toilet front clearance, 15″ centerline, 24″ shower entry).
   - Live door-swing collision prevention.
   - Wet-Wall Plumbing Stack Engine co-locating sanitaryware with up to 94% alignment.

4. **Commercial Trade Specifier & Sustainability**:
   - Zero-discrepancy investment counter and multi-currency Bill of Materials (₹ INR, $ USD, $ CAD).
   - Studio Kohler B2B MEP Cut Sheets (rough-in dimensions, P-traps, electrical lines).
   - Live environmental tracking (annual liters saved, CO2e offset).
